# PIX API Samples

This repository contains samples for the PIX API, a C++, C# or Python API to programmatically access information available through [PIX on Windows](https://devblogs.microsoft.com/pix/), Microsoft's debugging and profiling tool for DirectX.

For PIX API documentation, see the HTML reference shipped with your PIX install at `<PixInstall>\docs\html\index.html` — open it in a browser for the full interface reference, getting-started guide, and HRESULT details.

Each sample folder has its own `README.md` with build and run instructions.
